# How to Create a Song in Hookology

## Overview

A Hookology song is built in six stages: start a project, choose sounds, record a loop on each track, make variations, arrange them, and save. This guide takes you through each one on the FM-1 itself, with no computer needed.

It is written for Hookology 1.0. Compared with stock Melodee, you get six sound tracks, HERA chord sets, a free-tempo first take, a SECTIONS page for building the song and TRACKS and MIXER home pages.

**The look.** Hookology starts with its own splash: the hook mark, a note whose flag curls into a fish-hook, above the name and four short stripes in the track colours. The screen uses the **Stage** colours by default: a navy background with coral, gold, teal and violet for tracks 1 to 4. KNOB 1 to 4's labels always use those same four colours, so you can find the knob you're turning at a glance, and each page takes on the colour of the track you're on. For a bright screen, choose **Daylight** in Settings > COLOR (Melodee's NIGHT, DAY and the other colour sets are still there too). Text is set in Figtree; Settings > FONT switches to the blocky PIXEL font. When a button has several pages, the header shows which one you're on, such as 2/3 (tap the button again for the next); TRACKS and MIXER number the home pages the same way. The tempo shows in the header on MIXER, and for a moment on any page when it changes. To check the battery, press GLO: the bottom right of every GLO page says FULL, OK, LOW or EMPTY (LOW and EMPTY in red), or USB with a plug when a computer powers the FM-1, since the battery can't be measured then. Elsewhere a small red battery appears in the header only when it runs low.

You need an FM-1 running Hookology, and headphones or speakers. By the end you will have a saved project with a full arrangement that plays from start to finish.

## Key concepts

A project holds tracks, and each track holds patterns. A section is the same pattern number on every track, and the song is a list of sections.

| | Section A | Section B | Section C |
| --- | --- | --- | --- |
| Track 1 (drums) | Pattern 1 | Pattern 2 | Pattern 3 |
| Track 2 (bass) | Pattern 1 | Pattern 2 | Pattern 3 |
| Track 3 (chords) | Pattern 1 | Pattern 2 | Pattern 3 |

Whatever you put in pattern 2 on any track belongs to section B. A song might then be A ×4, B ×2, A ×4.

| Term | What it is | Limit |
| --- | --- | --- |
| Project | One saved song, with its sounds, patterns and arrangement | 32 slots |
| Track | One instrument or MIDI part | 6 sound tracks, 2 MIDI tracks |
| Pattern | One looping phrase on one track | 16 per sound track, 64 steps each |
| Section | Pattern 1 to 8 on every track, named A to H | 8 sections |
| Song entry | One step of the song: a section and how many times it repeats. Each repeat plays the whole section, to the end of its longest track, so A ×2 is the full section twice | 64 entries |

These controls do the same job on almost every page:

| Control | Job |
| --- | --- |
| ALGORITHM | Choose the track |
| PRESETS | Browse sounds for the selected track |
| SELECT | Turn the pages of the open section |
| KNOB 1 to 4 | Edit the four values shown on screen. In menus, lists, effect racks and other pages with rows, KNOB 1 picks the row and KNOB 2 changes its value |
| OCT+ | Enter or confirm. Hold it for the page's action sheet |
| OCT- | Go back or cancel |
| HOME | Return home. Tap again to switch between TRACKS and MIXER. Set the menu's HOME SELECT to PAGES and SELECT turns them too |
| ENV, LFO, EDIT | Open the sound's pages; press again for the next one. On the Prophet, FM6 and CZ-1, LFO opens the engine's own LFO pages first and ENV its envelopes; EDIT has the rest. The lit button and the page number in the header always belong to the page you're on. FM6 operator envelopes and CZ-1 envelopes live in EDIT, so ENV jumps there and EDIT lights |
| Hold EDIT | Undo |

On the home pages, a tap of OCT- or OCT+ shifts the keyboard octave instead.

## Step by step

This walkthrough builds a four-part song with drums, bass, chords and lead, and then shows how to add tracks 5 and 6. Do the steps in order the first time; later you can jump around.

### 1. Start a new project

1. Stop playback. New song only works while stopped.
2. Tap **SAVE** to open **PROJECT**. It is the first page; tap again for USER, then the preset list.
3. Turn KNOB 1 past the slots and **T** to **+**, then press **OCT+**.
4. Set the key and tempo: KNOB 1 ROOT, KNOB 2 SCALE, KNOB 3 TEMPO. Press **OCT+**.
5. Give each track a role with KNOB 1 to 4. Try DRUMS, BASS, CHORDS and LEAD. Press **OCT+** to create the song.
6. Hold **SAVE**, pick a free slot, press **OCT+** and choose **Save here**. From now on, autosave stores your changes after 5 seconds without touching anything.

Every pattern starts empty, and each role loads a suitable first sound.

### 2. Choose your sounds

1. Turn **ALGORITHM** to select a track.
2. Turn **PRESETS** to open the Patches browser.
3. The line under the Patches title shows the list you are browsing: All, Faves, Recent, then categories such as Bass or Pad. KNOB 1 changes it. KNOB 2 moves down the patches, which start at the top of the screen; turning it up past the first patch lights the list line to show you are at the top. Sounds that fit no category are under Other (a patch you save goes into a category when its name has a word like PAD, BASS or PIANO; to choose one yourself, open SAVE > USER, pick the slot, press OCT+ and turn KNOB 1 on Category, or use the Category column on the web editor's Library page). For a warm Rhodes-style electric piano with tremolo, try FM6's MELLOW TRM (F25).
4. Play the keys to audition it. **OCT-** goes back to the sound you had before browsing.
5. Tap **HOME** when you like it, then repeat for the other tracks.

For real drums, choose a sampled kit on the drum track: ACOUSTIC KIT, DEEP KIT, TIGHT KIT, BRIGHT KIT or DUST KIT. While playing, hold OCT+ on a home page for hard hits, or OCT- for ghost hits.

### 3. Tracks 5 and 6

A new project already has all six sound tracks. Tracks 5 and 6 are on the second page of TRACKS: turn **ALGORITHM** past track 4. Give them sounds the same way as in step 2. A project saved with four tracks keeps four; to add 5 and 6 to it:

1. Tap **HOME** and select a track that isn't a sampled kit. On a sampled kit, OCT+ plays hard hits instead of opening the sheet.
2. Hold **OCT+** and choose **Add track**. The browser opens on the new track.
3. Pick a sound. Turn ALGORITHM past track 4 to reach the second page of tracks.

All six tracks share the same voices, so more parts leave fewer notes for each chord.

### 4. Set up chords

HERA puts a full chord on every key, so one finger plays a whole progression.

1. Select the chord track.
2. Tap **SCL** until you reach **CHORD**.
3. Turn KNOB 1 (CHRD) to **HERA**.
4. Tap **SCL** again for **CHORD SET**.
5. Turn KNOB 1 (SET) to browse the 100 sets, playing keys to hear each one. The map shows the chord on each key.

KNOB 2 sets the voicing, and KNOB 3 and 4 add a strum. If you'd rather stay in your project's key, choose AUTO for automatic chords or AUTO2 to keep your melody on top.

**Richer chords in your key.** Instead of HERA, you can build chords from your scale and add colour to them:

1. On the **CHORD** page, turn KNOB 1 (CHRD) to DIA3 for three-note chords or DIA7 for seventh chords. Every chord stays in your key.
2. Turn KNOB 2 (VOIC) to LEAD. Each chord now moves as little as possible from the one before, so progressions sound smooth instead of jumping up and down. The first chord after PLAY or STOP starts in root position.
3. Tap **SCL** again for **CHORD 2** and turn KNOB 1 (EXTRA) to add a colour: 6, 9, 6/9, SUS2 or SUS4. On DIA chords the added note comes from your scale.

Try DIA7 with LEAD and EXTRA 9 for smooth, jazzy chords like Dm9 and G9. Chords hold at most four notes, so adding a 6 or 9 to a seventh chord drops its fifth. CHORD 2 appears for DIA3, DIA7 and the fixed shapes (MAJ, MIN, DOM7 and so on), and for any chord while STRUM is on; it only shows the controls that apply.

**Borrowed chords on the black keys.** With DIA3 or DIA7, the keys outside your scale play chords borrowed from outside the key, the surprise chords heard in pop and film music. In C major: C# plays Db, D# plays Eb, F# plays F#dim, G# plays Ab and A# plays Bb (on DIA7: Dbmaj7, Ebmaj7, F#dim7, Abmaj7 and Bb7). Try C, G#, A#, C for a big, triumphant ending. In a minor key it borrows the other way: in A minor, C# plays C#m, F# plays F#m and G# plays G#dim.

This is BORRW on CHORD 2 (KNOB 2), and it's on by default. It needs the track's QNT set to OFF, because SNAP, WHITE and ALL move every key onto the scale. Chord names use flats by default, so the screen shows Ab, Bb and Dbm rather than G#, A# and C#m; to spell them with sharps, set Settings > CHORD NAMES to SHARP.

**Looser and wider strums.** With STRUM on, CHORD 2 also has **SLOP** (KNOB 3) and **RANGE** (KNOB 4). SLOP makes each string land a little early or late at random, up to one string's gap, so the strum sounds played by hand; at 0 % it is perfectly even. RANGE set to 2 OCT plays the chord and then the same notes an octave higher, in the same strum time, for a harp-like run.

**Inversions in the name.** When the lowest note of a chord isn't its root, for example with VOIC set to INV1, the CHORD page names the bass after a slash: Bbmaj7/D.

**Arp patterns.** On the ARP page, MODE has 12 rhythmic patterns after REPEAT: PULSE, ALBRT (Alberti), WALTZ, CASCD (cascade), UPDWN (up-down), SYNCO (syncopated), GALOP (gallop), SKIP, BALAD (ballad), STRID (stride), DRIVE and LADDR (ladder). Each plays the notes you hold, counted up from the lowest, with its own accents and rests; RATE sets the speed and GATE the note length. Hold a chord and try WALTZ or GALOP.

### 5. Set the loop length and recording grid

1. Tap **SEQ** until you reach **PATTERN**. Set LEN with KNOB 1: 16 steps at 1/16 is one bar, and 32 is two bars.
2. Tap **GLO** for **TEMPO**. Set QNT to 1/16 if you want your takes tidied up. OFF keeps your timing exactly as played.
3. Hold **HOME**, then set **AUDIO CLICK** (the first item in Settings) to REC so you hear a click while recording. CLICK LEVEL sets its volume and gets much quieter toward the low end; with headphones, try 15 to 25%. CLICK SOUND picks BRIGHT or SOFT, a lower, gentler click.

Each track has its own length, so a one-bar drum loop can run under a four-bar chord part.

### 6. Record your first loop

Start with drums, because everything else locks to them.

1. Select the drum track.
2. Press **REC + PLAY** together. Recording starts and carries on across loops.
3. Play your part. Each pass adds to what is there.
4. Tap **REC** to stop recording. The loop keeps playing.
5. Hold **EDIT** if you want to undo the whole take.

If you'd rather program drums, stop playback and open **SEQ > NOTES**. On the drum grid, black keys choose the drum and white keys set its steps.

For a looser start, hold **HOME** and set **REC MODE** to FREE. On an empty project, tap **REC** and play with no click. Press **REC** on the 1 after your last bar, and the take sets the tempo and a 1, 2 or 4 bar loop.

### 7. Build up the other tracks

1. Turn **ALGORITHM** to the next track. You can do this while the loop plays.
2. Tap **REC**. Recording starts straight away, wherever the loop is, and each pass layers on top of the last.
3. Play your part, then tap **REC** to finish.
4. Repeat for each track. Only one track records at a time.

If you played something great without recording, hold **REC**. Capture writes your last bars into the pattern.

### 8. Fix mistakes

Open **SEQ > NOTES** to edit any note on the selected track.

- **KNOB 1:** move between notes
- **KNOB 2:** change pitch
- **KNOB 3:** change length
- **KNOB 4:** change velocity
- **Hold OCT- for a second:** delete the highlighted note, or every selected note. Tapping EDIT here opens the EDIT pages and deletes nothing
- **OCT+ on an empty space:** place a note

While stopped, playing a key at the cursor enters a note or chord there.

To start a track over, go to **TRACKS**, select the track and hold **OCT-**. After a second the lane says HOLD TO CLEAR and a red bar fills; keep holding until it's full and the track's part in the playing section is cleared straight away, even while the song plays. Let go early to cancel, and hold **EDIT** to undo.

### 9. Make variations

Your first loop is section A, because a new project starts on pattern 1. To make a chorus or a bridge, copy A into another section and change it there.

1. Tap **SEQ** until you reach **SECTIONS**. The eight white keys from F3 to F4 are sections A to H.
2. Hold the **B** key (G3) for one second. Everything playing is copied into B, and B starts playing. If B already has music, it asks first.
3. Tap **HOME**. On SECTIONS, REC builds or records the song, so leave the page to record a part.
4. Turn **ALGORITHM** to the track you want to change, tap **REC**, play the new part, then tap **REC** to stop.
5. To change single notes instead, open **SEQ > NOTES**. To replace a part, hold **OCT+** there and choose **Clear pattern**, then record a fresh one. If overdubbing left the same note stacked twice, choose Remove doubles there instead: it keeps the louder copy of each one in the pattern on screen, and EDIT undoes it. New overdubs don't stack: a note you play again close to the same note from an earlier pass replaces it. Clear pattern and Clear motion work straight away, even while playing, and EDIT undoes them.
6. To come back to B later, go to SECTIONS and tap **B** first.

Edits always go to the section that is playing. On **TRACKS**, the badge in the top left shows its letter, so check it before you record. If you changed the wrong one, hold **EDIT** to undo.

## Arrange, mix and save

The quickest way to arrange is BUILD: tap your sections in order on the SECTIONS page, and Hookology writes them into the song. Nothing has to play while you do it.

### Build the song

1. Stop playback, then tap **SEQ** until you reach **SECTIONS**.
2. Tap **REC**. The header says BUILD and the REC light stays on.
3. Tap section keys in the order you want them. Tapping A, A, B, C, B gives A ×2, B, C, B. Tapping the same section again adds a repeat instead of a new entry.
4. Tap **REC** when you're done. Press **PLAY** to hear the song from the start.

To rearrange, go back into BUILD:

- **KNOB 1:** pick an entry. The next tap adds a section right after it, so you can add in the middle of the song
- **OCT-:** delete the picked entry. If the same section is then on both sides, they join into one entry
- **Hold OCT-:** clear the whole song, after it asks
- **Hold EDIT:** undo the last tap or delete

An empty section can't be added, and holding a key in BUILD copies nothing, so you can't overwrite a section by accident.

### Record the song live

You can also perform the song. Start the loop playing (with Song mode off, so PLAY plays the loop), go to **SECTIONS** and tap **REC**. The header says SONG REC. Tap sections in order; each one starts when the section playing finishes its whole loop (its longest track with notes), so fills at the end of a long track are never cut off. Tap **REC** or **STOP** at the end, and the song list shows what you played.

### Change the song list

On **SECTIONS**, the knobs edit the song one entry at a time.

- **KNOB 1:** choose the entry. One past the last adds a new one
- **KNOB 2:** choose its section, A to H
- **KNOB 3:** set how many times it repeats, 1 to 16
- **KNOB 4:** make the song longer or shorter

On this page, **PLAY** follows Song mode (below): with it on, PLAY plays the song from its first entry; with it off, it plays the loop. With no song yet, it plays the loop. An entry shown as \* comes from an older song with rests or a change on one track; it still plays as it was. Holding **SEQ** from anywhere jumps straight to SECTIONS.

Press **OCT+** here to open the **Song** menu: KNOB 1 picks a row, KNOB 2 switches it, and OCT- closes it. **Loop song** starts the song again from its first entry instead of stopping at the end; the header shows LOOP (SONG LOOP while it plays). **Song mode** decides what PLAY does: with it on, PLAY on any page (TRACKS, MIXER, SECTIONS or a sound page) plays the song from its first entry, and SONG shows on the right of the header; with it off, PLAY plays the loop everywhere, so you can jam sections here with their keys. Both work while the song is playing and are saved with the project.

### Mix

1. Tap **HOME** until you reach **TRACKS**. Select a track and turn KNOB 1 for LEVEL or KNOB 2 for PAN (KNOB 3 is SWING, KNOB 4 STEPS). The four values appear while you turn, with that setting for every track listed underneath, and go away after a moment. On a drum track, hold a drum key and the four knobs belong to that drum: KNOB 1 its level, KNOB 2 TUNE, KNOB 3 DECAY and KNOB 4 TONE (the same settings as EDIT > DRUM SOUND). The first card shows the drum's lane and all eight drum levels appear underneath. Each key edits the exact drum it plays, so hold the same key you recorded with: the tom keys, for example, are three different toms. Let go and the knobs are the track's LEVEL, PAN, SWING and STEPS again. The held drum plays, and with REC on it records, so set drum levels with REC off.

   Changing STEPS while the song plays takes effect straight away. The track jumps to where it would be if it had always had the new length, so it lines up exactly the same way after STOP and PLAY, and anything you record on it plays back where you heard it.
2. Press **FX** to open a track's effects. The header shows the track's sound name in its colour, so you can see which track you're on as you turn ALGORITHM. Its Shared row leads to the reverb, delay, chorus and other shared effects. On an effects page, KNOB 1 picks a row and KNOB 2 changes it. To choose from the full effects list, press OCT+: KNOB 1 jumps between families, KNOB 2 moves through the effects, OCT+ chooses and OCT- cancels.

   For echoes, put **DELAY** in a shared slot (in the effects list under Space, after REVERB) and turn up FX SEND on the tracks you want echoed. KNOB 1 is MIX, how loud the echoes are. KNOB 2 is TIME, locked to the tempo: 1/16, 1/8T, 1/8, 1/8D, 1/4T, 1/4, 1/4D or 1/2. KNOB 3 is FDBK, from a single echo to long trails. KNOB 4 is TONE: turn it left and each repeat gets darker, like tape, or right and they get thinner. The right-hand echo comes slightly after the left for width, and changing TIME or the tempo glides smoothly. Only one DELAY runs at a time, as with REVERB. At slow tempos, settings longer than a second are halved to fit, and with ECO on the delay runs lighter and slightly darker. NOTE ECHO, in a track's own effects, is different: it replays the notes themselves on the track's sound, which uses more voices.

   To change one track's own sound, put an **insert** in one of its three FX slots: DRIVE (KNOB 4 picks the shape: SOFT, HARD, FOLD or FUZZ), CRUSH, FORMANT, TAPE or SPIT. In the effects list these sit under Dirt and Colour, before the note effects. Each slot can hold one, and they chain in order, slot 1, then 2, then 3, so DRIVE in slot 1 and CRUSH in slot 2 drives the sound first and then crushes it. A new insert starts at MIX 100 %. Inserts work before the track's level, pan, mute and FX SEND, so a crushed drum can still go to the shared reverb. Space and movement effects (REVERB, DELAY, CHORUS, PHASER, FLANGER, WIDTH and the pedals) stay in the shared slots, where one copy serves every track. Each running insert counts as a little more than one voice; a slot that is OFF, at MIX 0 or holding a note effect costs nothing. ROOM is no longer in the list; use REVERB.

   For a rhythmic chop, choose **GATE** or **STUTTER** from the **Rhythm** group of a track's effects list. Both follow a 16-step pattern locked to the tempo. GATE cuts the sound on the pattern's off steps; STUTTER repeats the last on step in their place. On the slot's page, KNOB 1 is DEPTH (for GATE, how far the off steps close, where 100 % is silent; for STUTTER, how loud the repeat is), KNOB 2 is RATE (1/8, 1/16, 1/32, 8T, 16T or 32T) and KNOB 3 is PAT, one of 16 patterns. The screen shows the pattern with the current step lit. While the song plays, step 1 of the pattern lines up with the track's step 1 and follows its swing; when stopped, it keeps its own beat at the tempo, so you hear it as you play. They chain with the other inserts, and like them they come before the track's sends, so the reverb and delay are chopped too. GATE costs almost nothing; STUTTER borrows a little memory while it is on.
3. Hold **GLO** to mute or solo tracks from the keys while you listen.
4. Play the whole song and watch the HOME header for **LOAD** and **OVER**.

For a mixing-desk view, tap **HOME** until you reach **MIXER** (right after TRACKS): a vertical strip per track with its sound's name turned on its side, a fader, a live meter, and PAN and FX SEND sliders. ALGORITHM picks the track; KNOB 1 is LEVEL, KNOB 2 PAN, KNOB 3 FX SEND and KNOB 4 MUTE (turn right to mute). The exact value shows in the header while you turn, for example T2 PAN L20.

To mix while the whole song plays, turn on **Song mode** and **Loop song** (OCT+ on SECTIONS), then press **PLAY** on MIXER. The song plays from its first entry and keeps repeating until you press STOP. With Song mode off, PLAY on MIXER plays the loop, as on TRACKS.

### Save and finish

1. Hold **SAVE** to store the project in its slot. Playback stops first.
2. To open the song at power-on, tap **SAVE** for **PROJECT**, press **OCT+** on its slot and choose **Boot**.
3. To record the finished song, connect the FM-1 by USB and record its stereo output in your audio app. That output includes all six tracks and the shared effects.

Projects are stored on the FM-1. To keep a copy on your computer, use the web editor's Projects page, and record any song you want to keep as audio.

### Start from a template

A template is your starting setup with no notes: the sounds on all six tracks, the effects, the key and the tempo. The FM-1 holds one template, and saving a new one replaces it.

To save your setup as the template:

1. Set up the sounds, effects, key and tempo you want, then stop playback.
2. Tap **SAVE** to open **PROJECT**.
3. Turn KNOB 1 to **T** (Template), just before **+**. Press **OCT+** and choose **Save as template**.

To use it:

- **Load it by hand:** on **T**, press **OCT+** and choose **Load template**. You get a new song with the template's sounds, empty patterns and a free slot picked. Hold **SAVE** to store it there.
- **New song:** **+** starts from the template. Tracks you keep as KEEP have the template's sounds, including tracks 5 and 6.
- **At power-on:** when no project is set to **Boot**, the FM-1 starts from the template.

### Record into a DAW

Set **MIDI OUT** to ALL and every track's notes go to your DAW as MIDI, each track on its own channel. On **SECTIONS**, the DAW's start plays your whole song.

1. Open the menu, pick **MIDI OUT** with KNOB 1 and set it to **ALL** with KNOB 2. KEYS sends only the keys you play.
2. Set **GLO > GLOBAL > SYNC** to **USB** so the FM-1 follows the DAW's tempo and start and stop (the same setting is in the menu as MIDI SYNC, under MIDI OUT). Leave it on OUT if you want the FM-1 to lead: it then sends its clock to the DAW.
3. In the DAW (Studio One, for example), make one instrument track per FM-1 track. Set each input to the FM-1 on that track's channel: track 1 on channel 1, up to track 6 on channel 6. Tracks 7 and 8 use their own CH setting.
4. Turn **monitoring off** on those tracks, or the notes go back to the FM-1 and play twice.
5. Choose what to record: go to **SECTIONS** for the song, or stay on **TRACKS** (or any other page) for the loop.
6. Put the DAW's playhead at **bar 1**, arm the tracks and press record. The song plays from its first entry; when it ends the FM-1 stops, so stop the DAW there.

What goes out is what you hear: patterns, recorded takes, chords, strums, ratchets, arpeggios and section changes. A muted track sends nothing, and when you solo tracks only those send, so you can record one track at a time. Notes coming in from the DAW are never sent back. Repeats from the MIDI DELAY effect are not sent.

Turn Loop song off (in the Song menu: OCT+ on SECTIONS) before recording a single pass. With it on, the song keeps repeating in the DAW too.

To play the recording back through the FM-1's sounds, stop the FM-1's own song, set **GLO > SYSTEM > ROUT** to **1-8** (channels 1 to 8 play tracks 1 to 8) and turn monitoring back on in the DAW. Starting the DAW from the middle of the timeline plays the FM-1's loop, not the song.

## The web editor

The editor runs in Chrome or Edge and follows the FM-1 live: turn a knob on the FM-1 and it moves on the screen. Plug the FM-1 in over USB, open the editor and press **Connect** (allow MIDI when Chrome asks). The pages are in the sidebar: LIVE, **Sound**, **Sequencer, Tracks and Song** under Play, **Library** and **6-OP FM** under Sounds, **Projects** and **Settings** under Device. **Daylight** at the bottom of the sidebar switches to the light colours.

Across the top, every track in your project has a chip with its number in the track's colour, its sound and its engine. Click one to work on that track. A track you add on the FM-1 appears there too.

On **Sound**, each button's pages appear as rows of four values, the label in the same colour as the knob that turns it on the FM-1. Drag a value up or down like a knob (hold Shift for fine steps), or double-click it to reset it. On a Prophet, FM6 or CZ-1 track the ENV card shows that engine's own envelopes, as the FM-1's ENV button does (the Prophet's filter and amplifier envelopes, FM6's pitch envelope; the CZ-1's are in its own panel), and the LFO card starts with the engine's own LFO. Prophet changes reach the FM-1 as you make them, without cutting notes; FM6 changes follow a moment after you stop.

**Piano roll.** On **Sequencer**, press **Piano roll** to see a synth track's notes on a keyboard grid. Choose a length under **New note**, then click an empty spot to add a note there (on the first step of a chord it adds one more note to that chord, up to 4). Click a note to remove it, or drag its right end to make it longer or shorter. **Octave up** and **Octave down** move the view. Every change goes to the FM-1 at once.

**MIDI files.** **Export MIDI** saves the selected track's pattern as a .mid file, with the tempo, ready to drop into a DAW. A drum track exports its hits as General MIDI drum notes (36 kick, 38 snare, 42 closed hat and so on). **Import MIDI** reads a .mid file and shows a preview first: which of the file's tracks to use, how many notes and steps, and anything that has to change to fit (notes off the grid, more than 4 notes on one step, notes past the last step). Nothing changes on the FM-1 until you press **Import**.

**Song.** The **Song** page shows the order SECTIONS plays, one entry per row: a section (A to H, or a rest) and how many times it plays in a row. Change an entry's section or its count, move it up or down, remove it, or press **+ Add a section** for a new one at the end. **▶** on a row plays the song from that entry. **Loop song** and **Song mode** are the same switches as OCT+ on SECTIONS. Stop the song before you edit it; every change goes to the FM-1 at once, and holding EDIT on SECTIONS undoes it. An entry you built on the FM-1 with different sections on different tracks shows as **\*** and stays exactly as it is, even when you move it.

**LIVE.** The **LIVE** page is for playing the FM-1 from the computer, at a gig or a jam. Across the top: **Play** (it does what the FM-1's PLAY does, so with Song mode on it plays the whole song), **REC** for the selected track, the **BPM** (drag it up or down, use − and +, or press **Tap** in time), **SWING**, the bar and beat, and the **Loop song** and **Song mode** switches. The eight **section pads** work like the SECTIONS keys: tap one and it plays from the end of the current loop (straight away when stopped); the section playing is filled in and the one coming next blinks. The **mixer** has a strip for every track with a level fader, **M** to mute and **S** to solo; click a strip's number to select that track. The **keys** play the selected track just as the FM-1's own keys do, through its scale and HERA chords, and REC records them. On the computer's keyboard, A W S E D F T G Y H U J K O L P ; play notes, Z and X change the octave, Space is PLAY, 1 to 8 tap sections A to H, C is REC and B is Tap.

## Tips and troubleshooting

Most problems in a big song come from asking the FM-1 to play too many notes at once, and the fix is to thin out chords, long tails or reverb.

Two settings in **EDIT > VOICE** help a heavy song (turn KNOB 1 to the last rows, then KNOB 2 to change them):

- **QUALITY** (Prophet, CZ-1, FM6 and SID tracks): FULL is the engine as designed. LIGHT does roughly half the work for nearly the same sound; only the very top end gets softer on bright sounds (above about 12 kHz on the Prophet, about 9 kHz on the CZ-1). FM6 saves less, about a fifth, and bright FM6 sounds soften a little above about 6 kHz. SID saves about a third and sounds a little darker above about 4 kHz. Drum kits have no LIGHT setting. The 909 is the heaviest kit, each drum ringing costing about as much as an FM6 voice. The CR78, FM and Sample kits get heavier with every drum ringing at once, and the FM-1 counts them that way, so a dense pattern on them leaves less room for other notes than a sparse one. The 808 and SID kits are the lightest. Try LIGHT on the Prophet first, as it saves the most; the CZ-1 is cheaper to begin with, so LIGHT there adds a smaller margin. In testing, a six-track song went from 80 glitches in 30 seconds to none with its Prophet on LIGHT, and kept even more room with its two CZ-1 tracks on LIGHT too.
- **VOICES**: ALL, or 1 to 8 voices for that track. Past the limit, a new note takes over the oldest one smoothly, never the lowest held note.

Both are saved with the project and stay when you change the track's sound. When the FM-1 is still busy, it fades the costliest notes that are already releasing, so you may hear a long tail end sooner instead of a crackle.

After changing QUALITY or VOICES, hold **SAVE** so the project keeps them. Loading an older save brings back its old settings.

To put the whole song on LIGHT at once, tap **GLO** for TEMPO and turn **KNOB 4 (ECO)** to ON. Every Prophet, CZ-1, FM6 and SID track then plays LIGHT, whatever its own QUALITY says, and **ECO** shows at the right of the header. ECO also switches REVERB to a light version: the same length of tail, slightly darker (it keeps what lies below about 5 kHz), and about a fifth of the load. In a reverb-heavy song this is the biggest saving of all. Turn it OFF and each track goes back to its own QUALITY. ECO is saved with the project, so hold SAVE after turning it on.

| What you see or hear | Why | What to do |
| --- | --- | --- |
| OVER appears, or the top notes of chords go missing | The song has passed the overload limit, and Hookology drops fading notes first, then the top of the fullest chord | Use one chord track instead of two, shorten long release tails, or turn on ECO, which makes REVERB much lighter (without ECO, REVERB costs about twice as much as other effects) |
| Crackling | The FM-1 is running out of time for each audio block. Prophet sounds cost the most, so a Prophet chord next to five other tracks is the usual cause | Turn on **ECO** (GLO > TEMPO, KNOB 4) to put every track on LIGHT at once, or set **EDIT > VOICE > QUALITY** to LIGHT track by track, Prophet tracks first. Still crackling: lower that track's **VOICES** (the row above), or remove effects one at a time |
| An edit changed the wrong section | Edits go to the section that is playing | Hold **EDIT** to undo, tap the right section on SECTIONS, then edit again. The TRACKS badge shows which section is playing |
| REC on SECTIONS opens BUILD instead of recording a track | On that page, REC builds the song (or records it, while playing) | Tap REC again to leave BUILD, tap HOME, then REC |
| STOP RECORDING FIRST when tapping a section | A track is armed for recording | Tap **REC** on another page to finish the take, then switch |
| STOP SONG TO SWITCH | The song is playing, so it decides the sections | Press **PLAY** to stop it, then tap a section |
| The TRACKS badge shows \* | The tracks aren't all on the same section | Tap a section on SECTIONS to put every track on it |
| Holding OCT+ plays a loud drum hit | A sampled kit is selected, so OCT+ is its hard-hit control | Select another track first |
| FREE recording doesn't start | A free take needs a project with no notes, a stopped transport and the internal clock | Start a new project, or use GRID |
| RECORDING FULL | The project's 1,024 timed notes are used up | Delete recorded notes you no longer need |
| PATTERN STORAGE FULL | The project's roughly 1,450 set steps are used up. Copying sections uses more of them | Clear patterns or sections you no longer need |
| PROJECT FULL or STORAGE FULL | The save doesn't fit. Your previous saved copy is safe | Erase a project you no longer need, or clear unused patterns |
| MEMORY FULL on an effect | There isn't enough working memory for it | Turn off another effect, then try again |

Tracks 5 and 6 have a few limits:

- Recorded knob moves (motion) only work on tracks 1 to 4.
- FM6 function settings return to their defaults when a project loads.
- USB 4-track recording captures tracks 1 to 4 only. Tracks 5 and 6 are still in the stereo mix.
